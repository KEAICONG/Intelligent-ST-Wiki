## 复习建议

这门课由 **xt 老师** 和 **cdm 老师** 共同授课。

首先，**简答题一定要认真背！**

简答题的内容相对固定，只要提前准备并认真背诵，基本能够覆盖比较稳定的分数，也可以显著降低挂科风险。

如果目标只是顺利通过考试，建议优先保证简答题部分。

如果想要拿到更高的分数，则需要特别注意 **选择题**。选择题的考查范围可能 **非常细**，尤其是 **《NLP复习-下》** 中的知识点，很多看起来不起眼的小点都有可能成为考题。

例如：

* 给出某个英文单词，判断其对应的词性；
* 判断某个词性标记所代表的类别；
* 考查 PPT 中比较细节的定义、符号和概念。

因此，想冲高分的话，不建议只看“大知识点”，一些细节内容也最好过一遍。
