## 《数智时代科技英语》

授课老师：**ZW**

**推荐程度：一般，比较适合想要拿高分的同学。**

老师人不错，平时课程压力不算大，不过偶尔会有 **听写**，另外每位同学都需要进行一次 **全英文 Pre**。

期末考试整体难度不高，只要愿意花时间背书，基本比较轻松。考试内容大多来自教材原题：

- **选择题**：很多内容可以不用懂，直接背教材中的选项，直接就是原题；

- **作文题**：老师通常会提前给出题目范围，提前准备即可。

> **额外吐槽：** 本来"跨文化交际"是没有期末考试的，但 2026 年政策调整后也 **增加了期末考**，所以现在这类课程不能完全指望“无考试”了。
