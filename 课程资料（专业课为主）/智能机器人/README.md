## 考试建议

建议多问几个不同班级的同学，**复习资料一定要尽量收集完整**。不同老师给出的考试范围可能并不完全一致，只参考一个班级的范围很容易漏掉内容！！！（血泪教训）

另外，真正能直接从 PPT 中找到的考试内容其实并不算多，复习时往往还需要依赖老师额外补充的资料。

据说从 **2026-2 学期以后**课程 PPT 会进行调整，因此现有资料后续大概率会失去参考价值，这里就不再附带旧版本材料。
