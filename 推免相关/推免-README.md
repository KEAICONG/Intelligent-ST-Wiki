## 前言

恭喜你选择了一条 **充满挑战**、但也可能带来丰厚收获的道路。

保研不仅是对学习能力的考验，也是对个人规划能力、执行能力和综合素质的长期磨炼。请放平心态，这是一场持续三年的“拉锯战”。在这个过程中，你可能会经历迷茫、焦虑、挫折，甚至产生放弃的念头。

不过，从近几年的趋势来看，学校的推免名额也在持续增加。以我们这一届为例，可以外推的名额由 **36 个增加到 48 个**，同时还有 **本硕博一体化、国家工程硕博士专项、卓越英才班本硕贯通** 等不同培养和推免渠道。整体来看，同学们能够选择的路径比以前更加丰富，获得推免资格的机会也在逐步增加。

但请始终坚持并相信：

**宝剑锋从磨砺出，梅花香自苦寒来**

### （一） [普通推免生](https://auto.hdu.edu.cn/2026/0828/c3745a299805/page.psp)


申请普通推免生，应同时满足以下条件：

1. **外语成绩要求**

   大学英语四级成绩在 **500 分及以上**，或大学英语六级成绩在 **426 分及以上**。

2. **课程与成绩要求**

   截至第六学期，须完成本专业培养方案中课程性质为必修的课内课程，且无不及格记录。

   同时，前六学期所修全部课内课程的平均学分绩点须位列**专业前 20%**。~~(实际上15%都不行啊)~~

### （二） [有特殊学术专长的推免生](https://auto.hdu.edu.cn/2026/0828/c3745a299805/page.psp)

申请有特殊学术专长的推免生，应同时满足以下条件：

1. **外语成绩要求**

   大学英语四级成绩在 **426 分及以上**。

2. **课程与成绩要求**

   截至第六学期，须完成本专业培养方案中课程性质为必修的课内课程，且无不及格记录。

   同时，前六学期所修全部课内课程的平均学分绩点须位列**专业前 50%**。

3. **高水平创新成果要求**

   须获得下列标志性高水平创新成果之一：

   - 在学校认定并代表学校参加的学科竞赛中获奖。以团队形式获奖的，团队成员排序前若干名者可申请，具体名次要求以正式文件为准；
   - 以第一作者身份获得国家发明专利或国防发明专利授权；
   - 以第一作者身份在学校认定的一级期刊及以上级别学术期刊中发表学术论文；
   - 以第一作者身份在学校认定的出版社出版学术专著；
   - 作为第一完成人获得其他经推免生遴选工作领导小组审定的高水平创新成果。

4. **教授推荐要求**

   须经三名本校本学科**教授**联名推荐。

   学生申请材料和教授推荐信须进行公示，公示期不少于 **3 天**。

### （三）“支教团”专项推免生

申请“支教团”专项推免生，应同时满足以下条件：

1. **外语成绩要求**

   - 普通专业学生：大学英语四级成绩在 **500 分及以上**，或大学英语六级成绩在 **426 分及以上**；
   - 英语专业学生：专业英语四级考试成绩须达到 **良好及以上**；
   - 艺术类专业学生：大学英语四级成绩在 **426 分及以上**；
   - 其他语种参照相应的同等水平要求。

2. **课程与成绩要求**

   截至第六学期，须完成本专业培养方案中课程性质为必修的课内课程，且无不及格记录。

   同时，前六学期所修全部课内课程的平均学分绩点须位列**专业前 50%**。

3. **身体条件与教学能力要求**

   身体健康，能够适应支教地区的艰苦环境，具有一定的教育教学能力，能够胜任支教工作。

4. **学生工作与志愿服务要求**

   在校期间具有学生干部经历，并取得较为优秀的工作成绩；同时应热心公益，具有较丰富的社会实践和志愿服务经历。

   在校期间有参军入伍服兵役经历，或参加国际组织实习经历的，可优先考虑。

### （四）[“2+2”辅导员](https://i.hdu.edu.cn/mnews/_s2/c2/6f/c14a49775/page.psp)

申请者须为 **中共党员或中共预备党员**，并符合《杭州电子科技大学推荐优秀应届本科毕业生免试攻读研究生实施办法》中规定的推免生基本条件，同时还需满足以下要求：

1. **英语要求**

   普通专业学生大学英语四级成绩须达到 **425 分及以上**；英语专业学生专业英语四级考试成绩须达到 **合格及以上**，其他语种参照相应水平要求。

2. **学业要求**

   截至第六学期，须完成本专业培养方案中课程性质为必修的课内课程，且 **无不及格记录**。

   同时，前六学期所修全部课内课程平均学分绩点须位于 **同年级同专业前 30%**，具体绩点计算办法以学校当年推免文件为准。

3. **学生工作与志愿服务要求**

   须积极参与学生工作和志愿服务，并满足以下条件之一：

   * 在校期间曾担任 **省学联（执行）主席**；
   * 在校期间担任以下任一职务 **满一年**，且考核评价为合格及以上：校团委副书记、部长或副部长（部长由教师担任的），校院两级学生会主席团成员，学院团委副书记，学生党支部书记或副书记（支部书记由教师担任的），班级班长或团支部书记，四星级及以上社团负责人；
   * 获评 **校级五星级志愿者、优秀学生干部、优秀团干部、“最美寝室长”**；
   * 获得 **省级及以上学生工作或志愿服务类荣誉**。

### （五）[本硕博一体化](https://https-auto-hdu-edu-cn-443.webvpn.hdu.edu.cn/2024/1213/c3754a273691/page.htm)

在满足学校 **2026 年学术/专业学位博士研究生招生简章**相关要求的基础上，申请硕博连读研究生须符合以下条件：

1. **课程与成绩要求**

   已完成硕士生培养计划规定的课程学习，学习成绩优良，平均成绩须达到 **80 分及以上**，且所有课程均无补考、重修记录。

2. **特殊情形申请要求**

   对于学位课成绩或英语成绩未达到相关要求，但已通过 **全国大学英语四级考试**，且在硕士阶段表现出较强研究能力的研究生，须具备以下科研成果条件之一：

   - 以**第一作者**在核心期刊及以上级别期刊发表或录用 **1 篇本专业相关学术论文**，其中导师第一作者、学生第二作者的情况亦予认可；
   - 获得**省部级及以上科技成果奖**，本人排名须在**前 5 名**；
   - 申请**国家发明专利**且已公开，本人署名须在**前 2 名**；
   - 出版**学术专著、教材或译著**，本人署名须在**前 2 名**；
   - 在全国性学科竞赛中获得**三等奖及以上**，本人排名须在**前 2 名**；或在赛区、省级学科竞赛中获得**二等奖及以上**，本人须排名**第 1 名**。团队奖成员排名按照正式获奖名单顺序认定。

3. **科研成果认定要求**

   上述科研成果及成果等级，以学校科学技术研究院最新规定为准。

4. **学科竞赛认定范围**

   所指学科竞赛主要包括：

   - 教育部学位与研究生教育发展中心组织的中国研究生创新实践系列大赛；
   - “挑战杯”系列竞赛；
   - 全国大学生智能汽车竞赛；
   - 以及学校相关文件认定的其他竞赛。

### 一些建议

有推免意向的同学，建议从大一开始主动了解相关政策，并尽早做好整体规划。比较重要的几个方面主要包括绩点、英语、科研和竞赛。

从近几年的情况来看，学术专长推免的竞争压力相对普通推免会 **小很多**，报名人数未达到名额上限（总名额的40%），剩余名额也会转入普通推免。

此外，近几年学校也新增了一些专项推免渠道，例如 **“国家工程硕博士专项”** 和 **“卓越英才班本硕贯通”** 等，不同专项在申请条件、报名时间和培养方式上会有所区别，有意向的同学可以提前关注学校研究生院和学院发布的通知，避免错过报名时间。

> [!IMPORTANT]
> **特殊学术专长申报提醒：**
>
> 建议提前准备好答辩 PPT。面试总时长约 **15 分钟**，其中 PPT 汇报控制在 **5 分钟左右**，**无英语问答环节**，同时记得携带 **个人简历**。
>
> 从 **2026 年开始**，特殊学术专长申报对材料格式的规范性要求进一步提高，建议尽早准备。
>
> **论文成果**需要准备：
>
>  检索证明；期刊封面；期刊目录；论文正文
>
> 其中，[检索证明](https://tsgin.hdu.edu.cn/13646/) 可以通过图书馆官网申请开具；**期刊封面和目录**如果无法自行获取，可以尝试联系出版社编辑。邮件沟通通常需要一定时间，建议至少预留 **3—5 天**。
>
> **专利成果**原则上需要提供原件。由于近几年部分专利已经逐步取消纸质证书，如果没有实体原件，可以提前咨询负责老师具体如何处理。以 2026 年为例，没有纸质版的材料基本上都由相关导师签字确认。
>
> 由于推免材料通常在暑假期间提交，而这段时间部分教授可能并不在校，因此建议尽量提前准备。对于需要 **三位教授** 签字的推荐信，最好在 **期末结束前** 就完成沟通和签字
>
> 整体来说，材料准备是一件非常耗费时间和精力的事情 (来自改了11版材料的人这样说到)，很多证明材料无法当天拿到 ，因此建议至少 **提前一周返校准备**，尽量不要把材料整理拖到最后几天。

本科没有必要从一开始就给自己太大的压力，按照自己的节奏稳步积累、逐步提升。

首先，一定要关注不同课程的**学分和成绩占比**。高学分课程对最终绩点 (GPA) 的影响更大，往往值得投入更多时间。即使一两门课程成绩不太理想，也不要轻易放弃，后续仍然有不少弥补和提升的空间。

大一、大二通常是课程最密集的阶段，一个学期的学分甚至可能接近大三一整年的课程量。因此，建议 **提前规划** 期末复习。

平认真完成课程任务，保持良好的学习态度。很多课程的最终成绩不仅取决于期末考试，平时作业、实验、课堂表现等同样会占据一定比例。 (大部分老师给平时分相对宽松，理念是：平时分不低于期末考试成绩；但有极少数老师评分非常严格，即使期末考试能考到 90+，平时成绩仍可能只有 70+。)

英语方面，四六级尽早通过。**六级 500 分** 能够满足不少院校的基本要求，如果能够达到 550 分以上，在部分院校的材料审核中会更有竞争力（2026 东南据说六级卡 600...）。如果四六级成绩暂时不理想，也可以根据自身时间安排考虑雅思、托福等英语成绩。

对于希望在本科阶段积累一些科研或竞赛成果的同学，也建议尽早开始准备 **(DDL为当年的8.31)**：

* **论文**：论文从研究、实验、写作到投稿、返修、录用，整个周期通常较长。如果有发表论文的计划，最好从大二甚至更早开始联系导师，准备科研项目。
* **专利**：专利需要预留较长的申请和审查周期。如果希望在推免阶段已经取得授权，需要尽早启动，条件允许大一就需要开始准备。同时，可以提前了解学校的专利申请流程，以及相关成果是否符合可以进行**专利预审**。
* **大创**：如果有机会，建议大一、大二就积极参与。大创本身不仅是一项项目经历，后续还可以围绕项目继续拓展论文、专利、竞赛等成果。
* **竞赛**：可以多尝试，但不必盲目追求数量。建议结合自己的时间成本、获奖难度和认可度进行选择（如果是想走特殊学术专长的同学，还需要进一步筛选竞赛类别）。性价比方面结合个人经验，推荐参加 **数学建模、统计建模、智能机器人大赛** 等比赛。同时，很多比赛的信息往往集中在不同学院和专业内部，因此，多和其他学院的同学、学长学姐交流，也是减少信息差的一种有效方式。

从我个人接触到的情况来看，对于大部分院校，推免过程中不同阶段关注的重点会有所区别：

**入面前：绩点 > 科研 >> 竞赛**

**入面后：科研 / 专业能力 > 绩点 >> 竞赛**

当然，这只是一个比较粗略的经验总结。不同学校、学院、导师和研究方向的评价标准差异很大，不能完全按照这一排序进行准备。

如果有志于申请 **计算机、人工智能等 CS/AI 相关方向**，还建议尽早培养一定的算法和编程能力甚至是准备 408（苦笑）。大部分 985 院校在夏令营、预推免考核中会安排机试，因此不要等到申请季才开始准备。

算法入门可以参考：

* [AcWing](https://www.acwing.com/)：比较适合系统学习基础算法，可以按照算法基础课、题单等逐步练习。
* [LeetCode 力扣](https://leetcode.cn/)：适合刷题和准备机试、面试，其中可以重点练习 [LeetCode Hot 100](https://leetcode.cn/studyplan/top-100-liked/)，对常见数据结构和算法题型覆盖比较全面。

> 建议优先使用 **C++** 进行练习

最后，不必因为本科院校背景而过度焦虑。每年都有不少学长学姐成功进入优秀的 985 高校和科研院所 **(直博请慎重)**。学校背景确实会在部分环节产生影响，但绩点、科研经历、专业能力、英语水平以及与导师研究方向的匹配程度同样重要。

所以，在自身条件允许的情况下，**大胆投递、积极联系！**
