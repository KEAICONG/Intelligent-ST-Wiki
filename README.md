# Intelligent-ST-Wiki

## 智能科学与技术专业学习指南

本项目旨在为智能科学与技术专业的同学提供学习建议、课程资料与实践经验，帮助大家更快建立专业认知，提升学习与实践能力。

## 写在前面

大家好，这里是 Mio。

本科阶段，我在学习和成长过程中得到了许多老师、学长学姐与同学的帮助。因此，我希望通过整理并分享这份资料，将这种开源共享的精神继续传递下去。

智能科学与技术是一门交叉性较强的专业，课程内容涉及人工智能、计算机、自动化、信息处理等多个领域。面对较为广泛的知识体系，初学者难免感到迷茫。本项目整理了部分专业课程复习资料、学习建议与个人经验，希望能够为大家的课程学习和能力提升提供参考。

在课程学习和课外拓展过程中，请大家善于使用 **AI 工具**。身处人工智能快速发展的时代，合理使用 AI 能够减少大量重复性工作，并辅助知识梳理、概念拆解与问题分析。但与此同时，也应保持独立思考，并对 AI 生成的内容进行必要的核实。

此外，也应重视 **信息检索能力** 的培养。无论是检索论文，还是查找培养方案、课程文件和相关通知，都应尽量先自行搜索与核实，逐步提升信息素养，避免过度依赖他人直接提供答案。

遇到不熟悉的知识点时，可以在 [哔哩哔哩](https://www.bilibili.com/) 等平台查找相关讲解，往往会有意想不到的收获。

同时，请定期查阅 [杭州电子科技大学自动化学院官网](https://ac.hdu.edu.cn/main.htm)，及时关注学院发布的重要通知。

### 2.我想保研

（ 一 ） 普通推免生： 

申请普通推免生，应同时满足以下条件：

1. **外语成绩要求**

   大学英语四级成绩在 **500 分及以上**，或大学英语六级成绩在 **426 分及以上**。

2. **课程与成绩要求**

   截至第六学期，须完成本专业培养方案中课程性质为必修的课内课程，且无不及格记录。

   同时，前六学期所修全部课内课程的平均学分绩点须位列**专业前 20%**。

---

### （二）有特殊学术专长的推免生

申请有特殊学术专长的推免生，应同时满足以下条件：

1. **外语成绩要求**

   大学英语四级成绩在 **426 分及以上**。

2. **课程与成绩要求**

   截至第六学期，须完成本专业培养方案中课程性质为必修的课内课程，且无不及格记录。

   同时，前六学期所修全部课内课程的平均学分绩点须位列**专业前 50%**。

3. **高水平创新成果要求**

   须获得下列标志性高水平创新成果之一：

   - 在学校认定并代表学校参加的学科竞赛中获奖。以团队形式获奖的，团队成员排序前若干名者可申请，具体名次要求以正式文件为准；
   - 以第一作者身份获得国家发明专利或国防发明专利授权；
   - 以第一作者身份在学校认定的一级期刊及以上级别学术期刊中发表学术论文；
   - 以第一作者身份在学校认定的出版社出版学术专著；
   - 作为第一完成人获得其他经推免生遴选工作领导小组审定的高水平创新成果。

4. **教授推荐要求**

   须经三名本校本学科教授联名推荐。

   学生申请材料和教授推荐信须进行公示，公示期不少于 **3 天**。
   
   ---

### （三）“支教团”专项推免生

申请“支教团”专项推免生，应同时满足以下条件：

1. **外语成绩要求**

   - 普通专业学生：大学英语四级成绩在 **500 分及以上**，或大学英语六级成绩在 **426 分及以上**；
   - 英语专业学生：专业英语四级考试成绩须达到 **良好及以上**；
   - 艺术类专业学生：大学英语四级成绩在 **426 分及以上**；
   - 其他语种参照相应的同等水平要求。

2. **课程与成绩要求**

   截至第六学期，须完成本专业培养方案中课程性质为必修的课内课程，且无不及格记录。

   同时，前六学期所修全部课内课程的平均学分绩点须位列**专业前 50%**。

3. **身体条件与教学能力要求**

   身体健康，能够适应支教地区的艰苦环境，具有一定的教育教学能力，能够胜任支教工作。

4. **学生工作与志愿服务要求**

   在校期间具有学生干部经历，并取得较为优秀的工作成绩；同时应热心公益，具有较丰富的社会实践和志愿服务经历。

   在校期间有参军入伍服兵役经历，或参加国际组织实习经历的，可优先考虑。

## 结语

希望大家都能度过一段充实而有意义的本科时光。

成长的道路不会始终平坦，途中难免会遇到迷茫、挫折与压力。

本科四年更考验的往往不是一时的天赋，而是长期坚持、持续积累和主动选择的能力。四年的时间足以让一个人实现改变，甚至甚至后来居上。

明确自己的目标，并为之持续努力。即使最终的结果与最初设想有所不同，这段认真投入的经历，也一定会带来属于自己的收获。

感到迷茫或疲惫时，也不要忘记暂时停下来，出去走一走、散散心。适当休息并不是逃避，而是为了以更好的状态重新出发。
